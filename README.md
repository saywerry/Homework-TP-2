## ДЗ по ООП, тестированию и git

Первая часть проекта: реализация классов Ingredients, Recipe и Shoppinglist. 
Вторая часть проекта: реализация ОЧЕНЬ креативных тестов с использованием pytest
Третья часть проекта: работа с гитом (ведение проекта) и спец.файлами.

## Использование

Установить зависимости:
bash
pip install -r requirements.txt

Запустить тесты:
bash
py -m pytest

Реализация классов находится в файле recipes.py.
Тесты находятся в файле test_recipes.py.
